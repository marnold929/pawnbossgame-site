# pawnbossgame.com

The Pawn Boss website (static HTML, no build step). Hosted on GitHub Pages.

- `index.html` — the home page
- `support.html` — the support page (the URL for the Meta store listing: https://pawnbossgame.com/support.html)
- `privacy.html` — the privacy policy (the URL for the Meta store listing: https://pawnbossgame.com/privacy.html)
- `CNAME` — tells GitHub Pages the custom domain
- `.nojekyll` — serve the files as they are
